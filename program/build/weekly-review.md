# Weekly review

Rest day, at the time they chose. Thirty minutes. Numbers first, then the weakest building, then the next seven days. The review is a page the agent opens for them, filled from the day logs, the island ledger and the money file. They answer the three questions at the end; the agent writes the next week into `day.json` only if a decision rule fired.

```markdown
# Week N · YYYY-MM-DD to YYYY-MM-DD

## The letters
| Mon | Tue | Wed | Thu | Fri | Sat | Sun |
|---|---|---|---|---|---|---|
| F/L/X | | | | | | S |
F: n · L: n · X: n · S: n. Most common letter: _.

## The numbers
| Number | Target / wk | Actual | Pace to goal |
|---|---|---|---|
| Money unit (units) | | | |
| Conversations / booked / shows | | | |
| Cash number (change) | | | |
| The one number | | | on pace / behind by _ |
| Sleep: lights out on time (nights) | 7 | | |
| Protein days at target | 7 | | |
| Reading minutes | | | |
| Practice minutes | | | |
| RHR / readiness average | | | |

## The buildings
Which island building did not move this week, and what is the smallest daily bar that would move it?

## What broke
One honest paragraph. What day broke, what broke it, which if-then would have caught it.

## The next seven days, not the next ninety
Three changes at most. Each one is a line in day.json or rules.json, named here.

## Decision rules that fired
From rules.measure.decisions. If one fired, the change is made now, not considered.

## To whoever they report to
Three lines: the letters, the one number vs pace, the one change.
```

Rules: no inflation of a letter, ever. A week with three X lowers the floor, it does not raise the lecture. If the one number is two weeks behind pace, the weekly plan changes; the ninety-day goal does not move mid-run unless the person decides it on this page.
