# Awesome Design (DESIGN.md library)

Source: github.com/VoltAgent/awesome-design-md (MIT), cloned at
`~/.claude/design-references/awesome-design-md/design-md/<brand>/DESIGN.md`.

1. `ls ~/.claude/design-references/awesome-design-md/design-md` to find the brand.
2. Read that brand's `DESIGN.md` (colors, typography, spacing, components, do/don't).
3. Use it as the design system for the build; pair with `design-taste-frontend` / `impeccable`.
   Take the language, not the logos or proprietary fonts — swap to licensed equivalents.

Update: `git -C ~/.claude/design-references/awesome-design-md pull`
